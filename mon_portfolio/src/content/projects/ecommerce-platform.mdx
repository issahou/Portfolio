# E-Commerce Platform

Une plateforme e-commerce moderne construite avec **Next.js 14 (App Router)**, **TypeScript** et **Tailwind CSS**.

## Fonctionnalités principales

- **Catalogue produits** : Filtrage, recherche, catégories, pagination infinie
- **Panier & Checkout** : Intégration Stripe (paiements, webhooks, remboursements)
- **Authentification** : NextAuth.js (credentials, OAuth GitHub/Google)
- **Espace Admin** : Dashboard analytics, gestion commandes, CRUD produits
- **Gestion stocks** : Temps réel, alertes rupture, variantes produits

## Architecture

```
src/
├── app/
│   ├── (shop)/          # Routes publiques (catalogue, produit, panier)
│   ├── (auth)/          # Login, register, password reset
│   ├── (admin)/         # Dashboard protégé (RBAC)
│   └── api/             # API Routes (webhooks, actions serveur)
├── components/          # Composants partagés (UI, formulaires)
├── lib/                 # Utils, DB, auth, paiements
└── types/               # Types TypeScript partagés
```

## Défis techniques relevés

1. **Server Actions** pour les mutations (ajout panier, commande) sans API Routes
2. **Optimistic UI** pour une UX fluide (React 19 useOptimistic)
3. **Database migrations** avec Prisma en production (zero-downtime)
4. **SEO dynamique** : metadata générées par produit, sitemap.xml auto

## Résultats

- **Lighthouse** : 98/100 Performance, 100 Accessibilité, 100 SEO
- **Core Web Vitals** : LCP < 1.2s, CLS < 0.05, FID < 50ms
- **Conversion** : +34% vs version précédente (WordPress/WooCommerce)
