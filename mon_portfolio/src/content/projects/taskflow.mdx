# TaskFlow - Gestion de Projets Agile

Application web collaborative inspirée de **Jira/Trello** pour la gestion de projets en méthodologie Agile/Scrum.

## Fonctionnalités clés

- **Tableaux Kanban** : Drag & drop (dnd-kit), colonnes personnalisables, WIP limits
- **Sprints & Backlog** : Planification, estimation (story points), burndown charts
- **Temps réel** : WebSockets (Socket.io) pour mises à jour instantanées multi-utilisateurs
- **Notifications** : In-app + email (nouvelles assignations, mentions, échéances)
- **Rapports** : Vélocité, cycle time, cumulative flow diagram (Recharts)

## Stack technique

| Couche | Technologies |
|--------|--------------|
| Frontend | React 18, TypeScript, Tailwind, Zustand, React Query |
| Backend | Node.js, Express, TypeScript, Prisma ORM |
| Real-time | Socket.io, Redis (pub/sub, session store) |
| DB | PostgreSQL (relationnel), Redis (cache, sessions) |
| DevOps | Docker, Docker Compose, GitHub Actions, Vercel/Railway |

## Architecture temps réel

```
Client A          Client B          Client C
   │                │                │
   └──────┬─────────┴────────┬───────┘
          │                  │
      ┌───▼───┐          ┌───▼───┐
      │ Socket.io       │ Redis │
      │ Server (x3) ◄───► Pub/Sub │
      └───────┘          └───────┘
```

- **Horizontal scaling** : Multiple Socket.io servers derrière load balancer
- **Redis Adapter** : Synchronisation des rooms/events entre instances
- **Presence** : Heartbeat + TTL Redis pour détection déconnexion
